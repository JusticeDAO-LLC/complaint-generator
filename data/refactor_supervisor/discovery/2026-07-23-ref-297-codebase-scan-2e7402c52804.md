## Resolution

The finding identified a real false-positive test path. The null-byte robustness
test caught every exception raised while generating an ontology and then passed,
so regressions in input processing, entity extraction, relationship inference,
or output construction could not fail the test.

Ontology generation supports embedded null bytes and returns the same structured
dictionary contract used for other text inputs. The test now calls the generator
without an exception handler, allowing unexpected failures to propagate through
pytest, and verifies that the result contains the required `entities`,
`relationships`, and `metadata` fields.
