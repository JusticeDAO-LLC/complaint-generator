## Resolution

The finding identified a real false-positive property test. The special-character
test caught and discarded every exception raised by ontology generation. Because
the assertion was inside the same `try` block, it also swallowed assertion
failures, allowing every generated example to pass without proving the stated
robustness property.

Special-character text is supported input and follows the generator's documented
ontology result contract. The test now lets extraction errors propagate so
Hypothesis can report and shrink counterexamples, and it verifies that every
successful call returns a dictionary containing the required `entities`,
`relationships`, and `metadata` fields.
