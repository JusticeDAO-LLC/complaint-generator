## Resolution

The flagged branch is the object-attribute fallback in the session-progress JSON
sanitizer. Best-effort fallback remains appropriate when `vars()` cannot inspect
an otherwise attribute-bearing object, but the handler previously covered both
attribute access and recursive conversion. As a result, an arbitrary failure
while sanitizing a nested attribute was silently discarded and replaced by the
parent object's string representation.

Attribute extraction is now isolated from recursive sanitization. Only the
documented `TypeError` from `vars()` triggers the string fallback, and that event
is logged with the object type and traceback. Recursive conversion runs outside
the handler, so unexpected serializer defects remain visible to callers.

## Focused Validation

`tests/test_ref_052_harness_json_attribute_sanitizer.py` verifies that an
attribute-access rejection is logged and safely falls back to a string, while a
failure raised by a nested attribute serializer propagates instead of being
swallowed.
