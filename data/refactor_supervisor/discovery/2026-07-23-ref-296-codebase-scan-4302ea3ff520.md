and used an unconditional assertion as its failure branch. That duplicated
pytest's exception assertion behavior and caused the branch to be classified as
a placeholder runtime path.

pattern. This directly verifies that path traversal raises the security-specific
exception with the expected base-directory escape message, while pytest reports
a normal assertion failure if validation unexpectedly returns.
